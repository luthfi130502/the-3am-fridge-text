## What it does

`main.py` (Python 3.13, standard library only) writes the fridge's
single 3:04 AM text to `/output/entry.txt` — one line, within the
140-character gate. The fridge keeps it short: it has counted the
visits, it knows about the cake, and it is done pretending otherwise.
